# dotfiles

Configuración personal de mi entorno Arch Linux + HyDE + Hyprland.

## Stack

- **OS:** Arch Linux
- **WM:** Hyprland
- **Shell:** Fish + Starship
- **Terminal:** Kitty
- **Editor:** Neovim (NvChad)
- **Bar:** Waybar + nwg-dock-hyprland
- **Launcher:** Rofi
- **Notificaciones:** Dunst
- **Theme:** HyDE con wallbash dinámico

## Instalación

    git clone https://github.com/allanms/dotfiles ~/dotfiles
    cd ~/dotfiles
    ./install.sh

## Atajos principales

| Atajo | Acción |
|-------|--------|
| Super + Enter | Terminal |
| Super + Space | Launcher |
| Super + F1 | Selector wallpaper |
| Super + F2 | Selector tema |
| Super + L | Bloquear |
| Super + V | Ventana flotante |
| Super + G | Game launcher |
| Super + 1-5 | Cambiar workspace |
| Super + Shift + S | Captura de pantalla |
